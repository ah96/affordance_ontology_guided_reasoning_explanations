# Ontology-Guided Affordance Reasoning for Explainable and Reliable Robot Navigation

This package contains a lightweight, fully Python-based prototype accompanying a workshop paper on ontology-guided affordance reasoning for robot navigation explanations.

## Overview

The project studies whether reasoning over an affordance ontology helps a robot identify the most relevant explanation factors for navigation problems. The motivating scenario is a **robot librarian** that has to fetch a book in a library. The robot can either use a direct shortcut corridor or a longer detour corridor, while semantic objects such as chairs, doors, cabinets, carts, and people may obstruct the route.

Instead of only detecting obstacles geometrically, the method reasons about:

- which objects are present,
- which affordances they have,
- what their current affordance states are,
- and how changing those states would improve or restore the robot's route.

## Files

- `main.tex`  
  Full LaTeX workshop paper draft.

- `refs.bib`  
  BibTeX references for the paper.

- `affordance_ontology_experiments.py`  
  Main benchmark script. It generates environments, runs all experiments, computes metrics, and exports plots and result files.

- `results/`  
  Output directory automatically created by the script.

## What the script does

The script builds procedural grid environments with:

- a **direct shortcut corridor**,
- a **longer detour corridor**,
- semantic objects such as `chair`, `door`, `cabinet`, `person`, and `cart`,
- affordances such as `movable` and `openable`.

It then compares:

1. **Ontology-guided affordance reasoning**  
   The method reasons over hypothetical object--affordance state changes and ranks them by how much they improve or restore the route.

2. **Semantic-only baseline**  
   A baseline that ranks unresolved objects by rough corridor relevance, without reasoning over affordance-state changes.

## Implemented experiments

The script currently runs three experiments:

### 1. Main benchmark
Evaluates whether ontology-guided reasoning identifies relevant explanation factors better than the semantic-only baseline.

### 2. Distractor-clutter robustness experiment
Adds increasing numbers of semantically irrelevant distractor objects to test whether the method remains selective in cluttered environments.

### 3. Incomplete-ontology robustness experiment
Simulates missing ontology knowledge by hiding some unresolved affordances, testing how robust the method is when the semantic representation is incomplete.

## How to run

Run the script from the command line:

```bash
python affordance_ontology_experiments.py
```

The script requires Python with the following packages installed:

- `pandas`
- `matplotlib`
- `seaborn`

## Output location

The script creates a directory named `results/` in the **same directory as the script** and writes all generated files there.

## Exported results

The script generates the following output files:

### Main benchmark
- `results/benchmark_cases.csv`  
  Per-environment summary statistics.

- `results/method_comparison.csv`  
  Precision@2 and Recall@2 for each environment and method.

- `results/summary.json`  
  Aggregated summary statistics for the main benchmark.

- `results/precision_recall_barplot.png`  
  Bar plot comparing ontology-guided reasoning and the baseline on Precision@2 and Recall@2.

### Incomplete-ontology robustness
- `results/ontology_noise_results.csv`  
  Per-environment results under different missing-affordance rates.

- `results/ontology_noise_summary.csv`  
  Mean Precision@2 and Recall@2 grouped by missing-affordance rate.

- `results/ontology_noise_robustness.png`  
  Line plot showing how performance changes as ontology knowledge becomes incomplete.

### Distractor-clutter robustness
- `results/distractor_robustness_results.csv`  
  Per-environment results for different distractor-clutter levels.

- `results/distractor_robustness_summary.csv`  
  Mean Precision@2 and Recall@2 grouped by distractor level and method.

## Result formats

The script exports results in the following formats:

- **CSV** for detailed and summarized tabular experiment results,
- **JSON** for aggregated benchmark summary statistics,
- **PNG** for publication-ready plots.

## Notes

- The benchmark is intentionally lightweight and does **not** depend on ROS, Gazebo, or any robotics simulator.
- The environments are procedural and abstract, which makes the benchmark easy to reproduce and suitable for a workshop paper focused on semantic reasoning.
- The natural-language explanation strings generated by the script are illustrative examples of how ranked explanation factors can be verbalized.
